# WeChat 8.0.79 · Observatory 0.1.17 公共目录版

本版替换 0.1.16 的模块 Binder 配置服务。微信进程直接通过 Android 系统文件服务读写本机公共目录中的配置；无需模块关联启动、常驻后台或临时打开模块页面。微信内部的实时 WebSocket 通道保持原有实现。

## 升级顺序

1. 覆盖安装相同签名的 `wechat-observatory-0.1.17-wechat8079-debug.apk`，在 LSPosed 保持启用并勾选微信。
2. **旧版用户先打开 Observatory 一次**，点“授权配置目录”。在系统文件选择器选择本机 **Documents**，点“使用此文件夹”并允许。程序会创建 `WeChatObservatory` 子目录，将旧私有配置迁移到其中；已存在的公共配置不会被覆盖。
3. 强行停止并重新打开微信，使新模块代码生效。进入微信设置 → Observatory 网关，按提示为**微信也授权同一 Documents 目录**。已经存在子目录时也可直接选 `Documents/WeChatObservatory`。
4. 确认网关地址、API Key 和两个开关正确。以后直接在微信网关设置里修改并保存，无需打开 Observatory；从最近任务划掉 Observatory 后再打开网关应仍可读写。

Android 为每个应用分别保存目录访问授权，模块的授权不能代替微信的授权。无需“所有文件访问”权限。选择器只接受本机主存储的上述目录，不能选择云盘、下载目录或其他位置。如果授权失效，可重新打开微信网关按错误提示重新授权，模块页面也始终保留授权按钮。

如果先在微信创建了空公共配置，再打开模块，程序不会覆盖公共文件。此时请在微信网关中重新填写地址和 Key，避免恢复旧配置覆盖你的新设置。

## 文件位置与清理

常见单用户路径：`/storage/emulated/0/Documents/WeChatObservatory/observatory.properties`。工作资料/多用户按各自的主存储授权，不硬编码用户编号。

配置包含 API Key，保存在公共目录中；请勿分享该文件。有相应文件访问权限的应用可能读到它。账户 wxid 仍由当前微信运行状态识别，不从配置文件指定。

卸载不会自动删除公共目录。请手动删除整个 **`Documents/WeChatObservatory` 文件夹**，其中还可能包含锁文件和中断保存留下的备份文件。微信内“清除配置”会清空地址和 Key，并保留会话编号元数据。卸载模块时收到系统卸载广播的微信进程会关闭运行通道；若系统未投递广播，请停止微信。

配置文件只在启动加载、打开网关及保存时读写，不增加定时读文件任务。手动修改公共文件或在模块页面保存后，重新打开微信网关读取即可生效。

## 实现与验证边界

- 移除 ConfigService、ConfigServiceClient 和 Binder 配置协议；保留微信内隔离系统主题的正常尺寸开关。
- Android Storage Access Framework 的持久目录授权仅用于系统文件访问，不连接 Observatory 进程。
- 所有读写使用稳定 `.lock` 文件的跨进程锁，临时文件写入同步后改名提交；异常中断恢复不得回退已提交的会话高水位。
- 私有旧配置只迁移一次；公共配置清空或后续手动删除不会再从旧私有配置恢复凭据。
- 自动化检查覆盖存储恢复、会话编号、并发操作、授权及文件服务行为；不能替代一加 Android 16 真机验证。

手机验收：覆盖安装 → 两端授权 → 查看配置 → 划掉模块 → 微信网关读取和保存 → 重启微信后连接 → 撤销微信目录授权后重新授权。确认前保持 PR 待合并。
