# WeChat 8.0.79 · Observatory 0.1.18 微信私有配置版

配置由微信进程自行读写，设置入口仍为微信设置 → Observatory 网关。移除公共目录授权、配置 Binder/Provider 和模块启动依赖。模块启动页改为安装与使用说明；实时 WebSocket 通道和隔离主题的小尺寸开关保留。

## 升级

1. 覆盖安装相同签名的 `wechat-observatory-0.1.18-wechat8079-debug.apk`；LSPosed 保持启用并勾选微信。
2. 强行停止并重新打开微信，使新模块代码生效。无需打开 Observatory 或允许关联启动。
3. 在微信设置 → Observatory 网关中重新填写服务根地址和 API Key，开启网关和实时 WebSocket，保存。
4. 从最近任务划掉 Observatory，再验证微信内配置读写、重启微信后自动连接和收发。

本版不读取旧模块私有配置或 0.1.17 公共文件，也不弹系统目录选择器。旧配置需重新填写一次，避免继续依赖失效的通信/授权途径。确认新配置后，可手动删除旧 `Documents/WeChatObservatory` 文件夹。

## 存储与清理

使用微信 `Context.getNoBackupFilesDir()/observatory/observatory.properties`。典型主用户路径为 `/data/user/0/com.tencent.mm/no_backup/observatory/`，实际通过当前微信 Context 解析，不硬编码用户编号。

文件只存本模块配置和会话预留元数据，不修改微信已有 MMKV。私有 AtomicFile 写入在后台完成并核验，运行期间使用内存快照，未保存配置时和删除后读取不会重建文件。进程启动直接加载，不以显示 Activity 或启动模块为前提。

微信内 **停用并删除配置** 删除本版专用文件、备份和临时文件，清空内存凭据与会话，关闭当前 WebSocket，并阻止旧配置继续提交新操作。已经交给微信原生发送队列或服务器的请求无法撤回。

卸载 Observatory 不会自动删除微信拥有的私有文件。请卸载前点击上述按钮；先卸载后可重新安装模块再清理，或用 root 删除专用目录。普通文件管理器不能访问微信内部目录，切勿为此清空微信全部数据。旧版本保存在其他位置的副本不由此按钮删除。

## 验证边界

自动化覆盖私有存储隔离、保存与异常恢复、进程重启会话编号、删除后无文件重建、迟到回调和删除后重建配置的旧操作隔离。构建产物另做 APK 签名、版本与 DexSQL 静态检查。自动化不能替代一加 Android 16 / LSPosed 2.2.1 真机测试。

手机验收：重新填写并保存 → 划掉模块后编辑 → 微信冷启动自动连接 → 收发消息 → 停用并删除配置 → 重启微信确认仍为空且未连接 → 重新保存恢复。手机确认前保持 PR 待合并。
